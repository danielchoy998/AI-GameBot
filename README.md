
AI Gamebot｜專案簡介

專案概念

本專案係一款融合「互動式 Chatbot」與「解謎遊戲」嘅教育型遊戲原型，玩家將透過 AI 助手嘅引導，逐步解開隱藏於神秘語言與符號中的謎題。

整體玩法結合：
	•	密碼與邏輯推理
	•	任務式關卡挑戰
	•	AI 對話互動
	•	隱藏式演算法與程式語法教學

⸻

遊戲玩法
	•	玩家進入一個奇幻或科技化的世界
	•	每一關都呈現一個謎語式任務（文字／代碼型）
	•	玩家可自由輸入訊息與 AI 助手對話
	•	AI 提供模糊但有幫助嘅引導，不會直接提供答案
	•	成功輸入正確答案後可進入下一關

AI 角色扮演一位世界中的知識守護者，具有有限知識，提供靈感而非解法。

⸻

遊戲目標與價值

此專案目標不單為娛樂，亦具教育性，透過遊戲化方式幫助玩家學習：
	•	基本演算法邏輯
	•	程式語法理解（如字串處理、迴圈、邏輯判斷等）
	•	問題解決能力
	•	與 AI 的 prompt 對話技巧

⸻

技術特點
	•	前端：HTML / TailwindCSS / JavaScript
	•	後端：Flask 伺服器處理對話邏輯
	•	對話功能：整合本地語言模型，支援多輪記憶與 streaming response
	•	遊戲資料：關卡以 JSON 結構儲存，便於擴展與管理
	•	完全本地化運行（不依賴雲端 API）

⸻

Prototype 示意關卡（倒轉咒語）

關卡提示：
Input: "apple" → Output: "elppa"
Input: "hero"  → Output: "oreh"

任務：
請解開 "flame" 的咒語

AI 助手提示：
「你有冇試過從反方向讀字？有時候，要睇清世界，需要從後望前⋯」

答案：emalf

學習重點：Reverse 字串、字元處理邏輯

⸻

適用場景
	•	LeetCode 初學者
	•	AI 教育應用設計
	•	有趣課堂互動工具
	•	Prompt engineering 入門者
	•	Game AI prototype 示範

⸻

📈 專案定位

本遊戲並非傳統對話體驗，而係一個融合「遊戲性 + 教育性 + AI 對話理解」的創新型學習工具。
遊戲化學習，讓演算法唔再沉悶，而係變成一場智慧冒險。
