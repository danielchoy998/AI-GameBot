# AI Gamebot | Project Overview
AI Gamebot｜專案簡介

## Project Concept
專案概念

This project introduces an educational game prototype that merges an interactive chatbot with puzzle-solving gameplay. Players engage with an AI assistant to progressively solve puzzles concealed within enigmatic languages and symbols.
本專案係一款融合「互動式 Chatbot」與「解謎遊戲」嘅教育型遊戲原型，玩家將透過 AI 助手嘅引導，逐步解開隱藏於神秘語言與符號中的謎題。

The core gameplay integrates:
整體玩法結合：
*   Cryptography and logical reasoning (密碼與邏輯推理)
*   Task-based level challenges (任務式關卡挑戰)
*   AI conversational interaction (AI 對話互動)
*   Subtle instruction on algorithms and programming syntax (隱藏式演算法與程式語法教學)

## Gameplay Mechanics
遊戲玩法

*   Players immerse themselves in a fantasy or technologically advanced world.
    (玩家進入一個奇幻或科技化的世界)
*   Each level features a unique puzzle presented as a text or code-based challenge.
    (每一關都呈現一個謎語式任務（文字／代碼型）)
*   Players interact freely with an AI assistant via text input.
    (玩家可自由輸入訊息與 AI 助手對話)
*   The AI offers ambiguous yet helpful hints, deliberately avoiding direct solutions.
    (AI 提供模糊但有幫助嘅引導，不會直接提供答案)
*   Correctly solving the puzzle unlocks the subsequent level.
    (成功輸入正確答案後可進入下一關)
*   The AI assistant embodies a 'knowledge guardian' within the game world, providing inspiration based on its limited knowledge base, rather than explicit answers.
    (AI 角色扮演一位世界中的知識守護者，具有有限知識，提供靈感而非解法。)

遊戲目標與價值

Beyond entertainment, this project emphasizes educational value through gamification, aiming to enhance player understanding of:
此專案目標不單為娛樂，亦具教育性，透過遊戲化方式幫助玩家學習：

## Technical Specifications
技術特點

*   **Frontend:** Developed using HTML, Tailwind CSS, and JavaScript. (前端：HTML / TailwindCSS / JavaScript)
*   **Backend:** Utilizes a Flask server to manage conversational logic and game state. (後端：Flask 伺服器處理對話邏輯)
*   **Dialogue System:** Integrates a locally run language model, featuring multi-turn conversation memory and real-time streaming responses. (對話功能：整合本地語言模型，支援多輪記憶與 streaming response)
*   **Game Content:** Level data is structured in JSON format, facilitating scalability and content management. (遊戲資料：關卡以 JSON 結構儲存，便於擴展與管理)
*   **Deployment:** Designed for fully local execution, independent of external cloud APIs. (完全本地化運行（不依賴雲端 API）)

## Prototype Level Example: "The Reverse Spell"
Prototype 示意關卡（倒轉咒語）

*   **Hints:** (關卡提示：)
    *   Input: `"apple"` → Output: `"elppa"`
    *   Input: `"hero"` → Output: `"oreh"`
*   **Task:** Decipher the spell for `"flame"`. (任務：請解開 "flame" 的咒語)
*   **AI Assistant Clue:** *"Have you considered reading the word from the opposite direction? Sometimes, gaining clarity requires reversing one's perspective..."* (AI 助手提示：「你有冇試過從反方向讀字？有時候，要睇清世界，需要從後望前⋯」)
*   **Solution:** `emalf` (答案：emalf)
*   **Educational Concept:** String reversal algorithms and character handling logic. (學習重點：Reverse 字串、字元處理邏輯)

## 📈 Project Positioning
📈 專案定位

AI Gamebot transcends traditional chatbot experiences by offering an innovative learning tool that synergizes gamification, education, and AI dialogue comprehension.
本遊戲並非傳統對話體驗，而係一個融合「遊戲性 + 教育性 + AI 對話理解」的創新型學習工具。

It aims to transform the study of algorithms from a potentially monotonous task into an engaging intellectual adventure.
遊戲化學習，讓演算法唔再沉悶，而係變成一場智慧冒險。
